# :yum: Junior

## :innocent: Motivación y experiencia

- [Robert Martin - The clean coder](https://www.amazon.com/Clean-Coder-Conduct-Professional-Programmers/dp/0137081073)

    El Tío Bob (Uncle Bob) comparte sus recomendaciones sobre cómo "sobrevivir" y tener éxito en la industria de TI. Este libro no se trata solo de habilidades técnicas. También presenta desafíos psicológicos y las luchas con ellos.

- [Robert Martin - Clean Code: A Handbook of Agile Software Craftsmanship](https://www.amazon.com/Clean-Code-Handbook-Software-Craftsmanship/dp/0132350882)

    A pesar de las críticas que pueda encontrar sobre este libro, seguimos creyendo que puede ser un recurso valioso para los nuevos desarrolladores a corto plazo. El libro presenta una colección de técnicas efectivas que pueden ayudarle a escribir código bien estructurado, legible y mantenible. Sin embargo, es importante no ver este libro como un evangelio y evitar convertirlo en un "culto de cargo" (cargo-cult). En su lugar, utilice este conocimiento de forma inteligente y seleccione las técnicas que mejor se adapten a sus necesidades y mejoren su estilo de codificación.

- [Steve McConnell - Code Complete: A Practical Handbook of Software Construction](https://www.amazon.com/Code-Complete-Practical-Handbook-Construction/dp/0735619670)

    A pesar de su edad, este libro aún puede considerarse una "biblia" para los desarrolladores, ya que proporciona una descripción general completa de la industria de TI. Ofrece una gran cantidad de consejos prácticos sobre cómo crecer y desarrollarse como un profesional de primer nivel.


## :bar_chart: Informática (Computer Science)

- [Thomas H. Cormen - Introduction to Algorithms](https://www.amazon.com/Introduction-Algorithms-3rd-MIT-Press/dp/0262033844)

    Este libro sirve como un excelente seguimiento a "Grokking Algorithms". Profundiza en los algoritmos de clasificación comunes y el trabajo con listas, proporcionando información más detallada. El estilo de escritura es accesible y amigable. Leer este libro será útil para prepararse para una inmersión profunda en el campo de los algoritmos.

## :pencil: C++

- [Scott Meyers  - Effective C++: 55 Specific Ways to Improve Your Programs and Designs](https://www.amazon.com/Effective-Specific-Improve-Programs-Designs/dp/0321334876)

    Este libro es el recetario definitivo para los fundamentos de C++. Aunque cubre las características de C++03, la información que proporciona sigue siendo valiosa y relevante. Las recomendaciones descritas en el libro son perfectamente adecuadas para los últimos estándares.

- [Jason Turner - C++ Best Practices: 45ish Simple Rules with Specific Action Items for Better C++](https://www.amazon.com/Best-Practices-Simple-Specific-Action/dp/B08SJSZKJ5)

    Esta es una recopilación de consejos para desarrolladores de C++ sin experiencia, centrándose en los errores más comunes. Las explicaciones son breves y van al grano. La mayoría de los consejos incluyen enlaces a recursos adicionales. Dado que el libro no ofrece un examen exhaustivo de cada consejo, se recomienda profundizar en cada uno de ellos en el futuro para comprender realmente el razonamiento detrás de los mismos.

- [Herb Sutter, Andrei Alexandrescu - C++ Coding Standards: 101 Rules, Guidelines, and Best Practices](https://www.amazon.com/Coding-Standards-Rules-Guidelines-Practices/dp/0321113586)

    Este pequeño libro describe las mejores prácticas comunes para escribir código en proyectos comerciales. Es una compilación de experiencias recopiladas de varias empresas. Este libro también fue una base para los [C++ Core Guidelines](https://isocpp.github.io/CppCoreGuidelines/CppCoreGuidelines). Se recomienda comenzar con este libro primero antes de visitar las C++ Core Guidelines. Le dará una primera impresión de las pautas de código utilizadas en los proyectos. Después de leer el libro, puede visitar el sitio web de las C++ Core Guidelines para conocer los enfoques aprobados más recientes.


## :electric_plug: Habilidades duras (Hard skills)

- [Eric Freeman, Elisabeth Robson - Head First Design Patterns: A Brain-Friendly Guide](https://www.amazon.com/Head-First-Design-Patterns-Brain-Friendly/dp/0596007124)

    Este libro es un comienzo perfecto para estudiar patrones de diseño. Como otra alternativa, también puede visitar [refactoring.guru](https://refactoring.guru/design-patterns), pero en caso de utilizar este libro, podrá tener mucha práctica sobre la marcha que le ayudará a comprender mejor las ideas de los patrones de diseño comunes.

- [Sanjay Madhav, Josh Glazer - Multiplayer Game Programming: Architecting Networked Games](https://www.amazon.com/Multiplayer-Game-Programming-Architecting-Networked/dp/0134034309)

    Este libro es una excelente introducción a la teoría de redes, explicando los fundamentos de las redes a través de ejemplos de videojuegos. Le ayudará a escribir su primera aplicación que funcione a través de una red y ganará experiencia práctica trabajando con redes en C++. Todos los ejemplos del libro están escritos usando C++11/14.
