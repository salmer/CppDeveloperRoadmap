# :gem: Fuentes de la comunidad

## :bookmark_tabs: C++ en General

- [CppReference](https://en.cppreference.com)
- [C++ Core Guidelines](https://isocpp.github.io/CppCoreGuidelines/CppCoreGuidelines)
- [Microsoft GSL C++ (Guidelines Support Library)](https://github.com/microsoft/GSL)
- [Noticias del Comité de Estandarización de C++](https://isocpp.org/)
- [C++ Online Compiler Explorer](https://gcc.godbolt.org)
- [C++ Insights](https://cppinsights.io/) - Ve tu código con los ojos del compilador: muestra cómo el compilador transforma plantillas (templates), lambdas, bucles basados en rangos (range-based loops), etc.
- [r/cpp](https://www.reddit.com/r/cpp/) - La comunidad de C++ en Reddit: noticias, artículos y discusiones.

## :exclamation: Fuentes alternativas para aprender C++

- [Learncpp.com](https://www.learncpp.com/) - Es un sitio web gratuito dedicado a enseñarte cómo programar en C++. Se actualiza regularmente.
- [Hackingcpp.com](https://hackingcpp.com/index.html) - El portal web todo en uno con diferentes colecciones de materiales relacionados con C++: libros, hojas de referencia (cheat sheets), grabaciones de conferencias, etc.
- [Awesomecpp.com](https://awesomecpp.com) - Una colección curada de recursos de C++.
- [Cpp Con (back to basics)](https://www.youtube.com/playlist?list=PLHTh1InhhwT5o3GwbFYy3sR7HDNRA353e)
- [C++ Weekly](https://www.youtube.com/@cppweekly) - El programa de YouTube de Jason Turner con episodios cortos semanales sobre características de C++ y mejores prácticas.
- [CppCast](https://cppcast.com/) - Un podcast para desarrolladores de C++ con entrevistas sobre el lenguaje, bibliotecas y la comunidad.
